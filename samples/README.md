# 取り込みの見本（すべて架空のデータ）

実在の生徒・成績ではありません。「取り込み」の動きを試すためのファイルです。

| ファイル | 中身 | 試すこと |
|---|---|---|
| `見本_名簿.txt` | 24人の名簿（番号 氏名） | 新しい成績表をつくるとき、名簿の欄に貼り付け |
| `見本_成績表.xlsx` | Excel（タイトル行つき・シート2つ） | 見出しの行・列の役割の自動判定 |
| `見本_成績表_ShiftJIS.csv` | 日本語版 Excel の CSV | 文字化けせずに読めること |
| `見本_成績表_文字入りPDF.pdf` | 文字の入った PDF | PDF の文字から表を作る |
| `見本_成績表_スキャンPDF.pdf` | 画像だけの PDF（スキャン） | 端末内の文字認識 |
| `見本_写真_きれいな表.png` / `見本_写真_斜めから撮影.jpg` | 表の写真 | 傾き・遠近の補正と文字認識 |
| `見本_写真_手書き風（読み間違いの例）.jpg` | 手書き風の数字 | **読み間違いが多い例**（確認画面で直す） |
| `見本_Excel書き出しの例.xlsx` | アプリが書き出す Excel の例（架空の40人） | 評定一覧（転記用）・学期ごとの詳細・入力データ・配点とルール・人数の分布 |

## 試し方

1. ホームで「見本で試す」を押す（名簿は同じ氏名）。または「新しい成績表をつくる」で、名簿の欄に `見本_名簿.txt` を貼り付ける。
2. 「入力」→ 右上「取り込み（Excel・PDF・写真）」→ ファイルを選ぶ。
3. 列の割り当て → 生徒との照合 → 「この内容で入力する」。気に入らなければ「元に戻す」で全部取り消せる。
