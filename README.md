# かんたん成績

観点別の **A・B・C** と **5段階評定** を、手入力・Excel・PDF・写真から。

**▶ アプリを開く：https://dora9991.github.io/kantan-seiseki/**

![](https://img.shields.io/badge/通信なし-端末の中だけで動きます-2f6fda)

## できること

- 成績に入れる項目（定期テスト・単元テスト・小テスト・ワーク・プリント・問題集・自由に名前をつけた項目）と、観点ごとの配点を決める
- 名簿（名前なし・番号だけでも可）、学期制（3学期・2期制・通年）、評価の観点（追加・変更可）
- A・B・C の境目（何％以上か）は、あとからいつでも変更できる
- 5段階評定は、A=3・B=2・C=1 などの点の付け方、合計点の区切り、**BBB＝4 のような特別ルール**まで変更できる
- 手入力（表計算のように）、または **Excel・CSV・PDF・写真から取り込み**（確認画面を通してから入力。1回で全部取り消せる）
- 結果は観点別の％・A/B/C・評定と、**なぜその評定か**の根拠つき。Excel・CSV に書き出せる

## データの扱い（大事）

- 名簿も成績も、**このブラウザの中だけ**に保存されます。サーバーはなく、外へは送られません。写真の文字認識も端末の中で動きます。
- ブラウザの保存は、キャッシュの消去や、長く開かないときなどに消えることがあります。**「保存ファイル（.json）」を定期的に書き出してください。**
- **学校の共用パソコンでは、使い終えたら保存ファイルに書き出して、成績表を削除してください。**
- 名簿は出席番号だけでも使えます。画面を人前で操作するときは「名前を隠す」を使えます。

## 写真・スキャンの読み取りについて

罫線のある表を、まっすぐ・大きく・明るく撮ってください。印刷された数字・A/B/C は、合成した表での確認ではほぼ正しく読めました。
**手書きの数字は読み間違いが多い**ので、必ず確認画面で確かめてください。強いピンぼけは読めません。氏名は漢字の読み間違いがあるため、番号の列がある表を推奨します。

> 実際の成績表・実際の写真での確認は、これからです。結果は、必ず先生ご自身の目で確かめてください。
